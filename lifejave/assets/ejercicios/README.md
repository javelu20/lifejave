# Imágenes de referencia de ejercicios

Coloca aquí los PNG. **El nombre de archivo debe ser EXACTAMENTE el slug de la
lista** (todo en minúsculas, sin acentos, con guiones). Después descomenta su
línea en `app/src/lib/imagenesEjercicios.ts`.

- Offline-first: solo archivos locales, nunca URLs remotas.
- Recomendado: PNG cuadrado (p. ej. 512×512).
- 33 archivos únicos para 36 ejercicios (3 se comparten entre sesiones).
